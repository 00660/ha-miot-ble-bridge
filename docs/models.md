## 已知限制

- **米家体脂秤 S400**：上游未实现抱婴称重和平衡测试。 3.1005 按实际协议使用千克乘 10，3.1006 使用欧姆乘 10。 同步单位和电量状态按真实 action 参数枚举处理。
- **米家人体传感器 2S**：绑定期间需要保持请求配对广播。
- **米家温湿度计 3 mini**：仅使用国区 PID 0x55B5，海外 0x5BEA 不能替代。
- **米家温湿度计 3 Pro**：真机日常使用广播，只在按键唤醒后供手机连接。
- **米家夜灯 2**：云端 model 未在上游明确，目录使用真实硬件型号。 详情页偶发连接超时，删除后重加需要先清除本地绑定。 控制走 NUS 文本协议；上游未提供自动化触发事件。
- **米家驱蚊器智能版（实验）**：Legacy PSK 绑定仍未实机验证，暂不作为正常可用型号开放。 实验协议路径；扫描形态、dev_sign 和云端 PSK 接口仍缺实测。 上游未实现驱蚊器定时任务和 RTC。
- **米家 LED 灯泡蓝牙 Mesh 版（不可用）**：该型号需要 BLE Mesh 配网与合法设备身份，上游 PID 仅推断且绑定返回 -27。 保留协议研究目录，不能用普通 BLE 桥接添加或控制。

## 配置与数据规则

每台设备的型号、属性来源、动作、事件参数和虚拟状态独立保存。公开属性逐项选择；协议内部的序列号、地址和兼容占位数据由集成维护。没有属性来源时可用虚拟值，实体未知或离线时不回退成虚拟数据。

型号间同一属性名可能有不同类型、枚举或对象号。门窗 3 的电量是正常 / 低电枚举，温湿度计 3 mini 的广播对象号保留实测例外，牙刷充电枚举按型号分别定义。体脂秤的整数体重、阻抗和真实时间戳按相应单位转换，不用其他传感器的帧格式代替。

每一帧只包含一个加密对象，符合 31 字节广告限制。手机直连控制型号共享一个可连接实例，空闲时轮转，连接后保持同一设备，配对窗口优先。
